# machinelearning


Melanjutkan Tugas Terstruktur Pertemuan 7 mengenai Data Mining. Saya mencoba untuk menambahkan menjadi 4 metode klasifikasi dan diterapkan metode Supervised Learning dengan menggunakan 30 sampel data yang dianalisis menggunakan platform Orange, sebuah perangkat lunak visualisasi dan analisis data berbasis komponen. Data yang digunakan mencakup beberapa fitur kategorikal seperti jenis kelamin, pendidikan terakhir, jenis atap rumah, dan jenis lantai rumah, dengan target klasifikasi adalah Kategori Masyarakat (Miskin atau Tidak Miskin).
Empat metode klasifikasi digunakan dalam analisis ini, yaitu Decision Tree, Random Forest, Naive Bayes, dan K-Nearest Neighbors (KNN). Masing-masing algoritma memiliki karakteristik tersendiri: Decision Tree membangun model berbasis aturan-aturan keputusan dari data; Random Forest merupakan ensemble dari banyak decision tree untuk meningkatkan akurasi; Naive Bayes menggunakan pendekatan probabilistik berdasarkan Teorema Bayes dengan asumsi independensi antar fitur; dan KNN mengklasifikasikan data berdasarkan kedekatan dengan tetangga terdekat di ruang fitur.
Penggunaan Orange memudahkan proses eksplorasi data, pemodelan, dan visualisasi hasil tanpa memerlukan pengkodean kompleks, sehingga sangat sesuai untuk eksperimen dengan skala data kecil seperti 30 sampel. Hasil dari analisis ini diharapkan dapat memberikan gambaran awal tentang kemampuan berbagai algoritma supervised learning dalam mengklasifikasikan kondisi sosial ekonomi masyarakat secara cepat dan efisien berdasarkan atribut sederhana rumah tangga.
